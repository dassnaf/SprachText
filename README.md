# SprachText

WhatsApp-Sprachnachrichten → Text, komplett offline auf dem Handy.
Teilen-Menü → „SprachText“ → Pop-up mit Stichpunkten, Volltext zum Aufklappen.

Voraussetzung: Android 13+, Google-Spracherkennung mit deutschem Offline-Paket.
APK bauen: Projekt in ein GitHub-Repo hochladen → Tab „Actions“ → „APK bauen“ → Artefakt „SprachText-apk“ laden.
